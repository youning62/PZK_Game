# 系统流设定（第二阶段：破产之后）

> 第一章不出现系统。本文件记录系统觉醒后的核心规则，供后续章节实现。

## 背景
潘子恺在一次看似即将发展为亲密关系的约会中遭遇仙人跳，资产几乎全部被骗走。
陷入绝望时，一个神秘系统在他脑海中觉醒。

## 核心规则：女神报销系统

1. **女神评分**：系统会给潘子恺遇到的每位女性打出「女神评分」（0–100，系统主观标准，可作为笑点：评分说明经常很离谱）。
2. **报销**：潘子恺为 **评分 90 分以上** 的女神花的钱，系统全额报销（可设计额外返利/倍率作为后期成长）。
   - 为评分不足 90 的人花钱 → 不报销，真金白银自掏腰包（他现在是穷光蛋）。
   - 喜剧点：他必须"花钱才能变有钱"，但钱只能花在女神身上。
3. **代价（诅咒）**：系统存在期间，潘子恺的下体永远没有反应（阳痿）。
4. **解除条件（针对单个女神）**：当某位评分 90 以上的女神对他的 **好感度达到 90 以上**，他才会对 **这位女神** 恢复反应。对其他人依然无效。
   - 也就是说：钱能靠系统报销，心动不能。必须真心打动对方。
   - 这和第一章的主题一致：她在意的是「真诚」，不是钱。

## 与现有变量的衔接
- `yyl_aff`：第一章好感度沿用到后续章节（上限 100，规则中的"好感度 90"直接对应这个数值）。
- `sincere`（隐藏真诚值）：建议作为好感度能否突破 90 的门槛之一，防止纯靠花钱刷好感。
- 后续需新增：
  - `goddess_score = {}`：女神评分表，例如 `{"yyl": ?}`（杨永麟的评分是否 ≥ 90、系统给她打分时的反应，都可以做成伏笔/笑点）
  - `reimbursed_total`：累计报销金额
  - `system_unlocked = set()`：已恢复反应的女神（好感 ≥ 90 时加入）

## 写作注意
- 幽默点来自反差：前期的「顶级情圣」现在既没钱、又"不行"，只能靠真心。
- 保持轻度成人向喜剧：用暗示、吐槽、系统提示语制造笑点，不写露骨描写。
- 杨永麟与骗局的关系仍不揭示；系统给她的评分和她的好感进度可以成为悬念工具。
