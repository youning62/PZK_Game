# 纯爱致富系统 · 设定与实现

> 代码：`game/system.rpy`（状态、规则函数、界面）、`game/hud.rpy`（`sys_hud`）。
> 剧情：`Chapter3.rpy`（第二章 浪与骗局）、`Chapter4.rpy`（第三章 骑手潘师傅 · 系统觉醒）、`Chapter5.rpy`（第四章 前上司李轩翔）。

## 核心规则（游戏内「系统 → 规则」页同样列出）

| # | 规则 | 实现 |
|---|---|---|
| 1 | 只扫描**成年女性**，颜值评分 ≥ 90 才能成为攻略对象；已婚者、未成年人不扫描 | `bind_target()` 拒绝 < 90 的对象；扫描演出 `call sys_scan(tid)` → `target_card` |
| 2 | 每个对象独立好感度 0–100%，≥ 90% 视为攻略成功 | `targets[tid]["aff"]`，`love(tid, delta)` 带飘字和音效 |
| 3 | 攻略相关消费用「纯爱卡」**预授权**：刷卡前实时审核，通过由系统支付，驳回则刷卡失败 | `call sys_audit(item, amount, category, verdict, comment)`；`credit_limit` 随进度提升（新手期 ¥3,000 → 任务二后 ¥8,000） |
| 4 | 攻略成功发放奖金 = 基础奖金 × (1 + 0.1 × 已完成任务) × 真诚系数(0.8–1.5) | `bonus_estimate(tid)`；第一个对象基础奖金 ¥10,000,000 |
| 5 | **纯爱封印**：对已绑定对象，好感度 < 90% 时宿主对其"功能性失灵"；仅针对该对象 | `targets[tid]["sealed"]`；演出 `call seal_alarm(line)`；立绘差分 `pzk delivery sealed` / `pzk casual sealed`（符纸梗，不露骨） |
| 6 | 系统**不能**控制任何人的感情，不提供精神控制；好感只能靠剧情与选择 | 第三章系统亲口拒绝："那叫犯罪。而且不浪漫。" |
| 7 | 不支持七天无理由退货 | 梗 |

### 系统的性格
毒舌、一本正经、偶尔比宿主先一步看穿他（第四章抓娃娃店："系统知道。所以这次，只是例行提示。"）。
它不剧透攻略对象的过去（"那是她的事"），这一点要在后续保持。

### 运行中的梗（每次回来都换一层意思，最后一次反转）
- **报销审核**：豆浆油条被拒（"李轩翔不吃你的早餐"）→ 兰博基尼被拒（"约会交通费不包括车辆所有权"）→ 给她买的煎饼秒批（"李轩翔吃你的早餐了。审核通过。"）
- **纯爱封印**：第一次他慌（"我什么都没想！好吧我想了一点点"）→ 第二次他真的什么都没想，系统只做"例行提示"。最终解除时应当是一个情感时刻而不是色情时刻。
- **"可以"**：当年 PPT 打回 17 次后的批注 → 第四章会议上她再写一次。留给好感 90% 时再用一次。
- **奇怪的订单备注**："放在黑色高跟鞋旁边" → "别按门铃，敲三下" → "第三排第七台机器旁边，别说话" → 章末又一次"放在黑色高跟鞋旁边"（杨永麟回归伏笔）。

```

lxx_honest_reunion / lxx_pitch / lxx_meeting_style / lxx_claw / lxx_shark / lxx_suit
```
所有状态均为 `default`，读档兼容。第一部的 `zb` / `sincere` 继续沿用（真诚值影响奖金系数）。系统觉醒前，右上角和飘字都不显示任何数值（数值只在内部记录）。社死值已删除。

## 李轩翔 · 外形（第三版，Gemini 生成）
- 以参考照片（`tools/art/ref/lxx_ref_*.jpg`）的脸为基础生成的女性形象：蜂蜜金短发、无框茶色眼镜、红唇。
- 职业装（黑西装、白丝衬衫、包臀裙、黑丝、细高跟）：10 个表情，含吐舌头。定妆照 6 号，用户已审核。
- 红色皮衣（晚上十点后 / 私下）：5 个表情，含吐舌头。定妆照 3 号，用户已审核。
- 流程：`genai_lxx.py`（Gemini 生成，key 在 `~/.config/pzk/gemini_key`）→ 用户审核定妆照和表情 → `import_lxx_genai.py`（Vision 抠图，统一到 1024x1536 画布）→ `gen_lxx_cg.py`（两张 CG）。
- 规则：所有人物的定妆照必须先给用户审核，通过后才能使用。

## 李轩翔攻略篇规划

**已实现（第四章，好感约 25–55%）**：三种接近失败 → 深夜订单重逢 → 报销审核 → 骑手视角发现岛团外卖刷单 → 三种方式交付证据（冲进会议室 / 一页备忘录 / 煎饼夜宵）→ 二十分钟会议 → 凌晨抓娃娃店（隐藏任务）→ 新任务「和她吃一顿不是工作餐的饭」。

**后续（未实现）**：
1. **没有议程的饭**（任务四）：她不会接受"约会"，所以他得发明一个她无法拒绝的议程。好感 → 60%。
2. **张总的报复**：项目暂停让张总丢了承销费，他开始给李轩翔穿小鞋；潘子恺第一次想用系统额度"帮她"，被系统驳回——"她不需要被买单，她需要被站在一起"。
3. **四年前那件事**（重大反转）：当年潘子恺离职前出过一次乌龙指交易错误，他以为是系统 bug 自动撤回了；其实是李轩翔连夜补仓、自掏腰包补了亏损，并替他背了内部处分。所以她"刚好"晚升了一年 MD。
4. **他开始不想要奖金**：好感 80% 左右时，他发现自己在算的不再是一千万。系统检测到"宿主攻略动机发生变化"，奖金系数上升——但他不知道。
5. **90%**：封印解除 + 奖金结算。解除那一刻应当用"痛—笑—痛"：真话 → 一个系统的笑点 → 回到真话。

## 后续攻略对象（方向，不同于御姐类型）
- **沈眠**（第四章末已点名）：28 岁，投资机构创始合伙人，元气、话多、什么都想投，喜欢"有故事的人"。和李轩翔是老对手。
- **一位创业公司 CTO**：社恐、毒舌、只在代码里温柔。
- **外卖站点附近的面馆老板**：豪爽、能喝、看不起有钱人，恰好也看不起现在的潘子恺。
- **杨永麟**：不是攻略对象（至少暂时不是）。她以"放在黑色高跟鞋旁边"的订单回到城里。她和骗局的关系、和"K"的关系继续保持悬念。系统对她的扫描结果应当是"无法扫描"——这是一个大伏笔。

## 写作守则
- 成人喜剧靠双关、黑屏、系统提示和吐槽，不写露骨描写。
- 颜值评分只存在于系统内部；角色从不当面说分数（第三章系统亲口规定）。
- 每个攻略对象都要有独立的事业、判断力和不为钱所动的理由。
