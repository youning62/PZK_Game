- **类型**：恋爱喜剧 GALGAME，搞笑、无厘头，轻度成人向幽默，多选项、多结局，后期是系统流。

## 1. 怎么运行和测试

1. **运行**：Ren'Py SDK 8.4.1。用启动器打开 `PZK_GAME` 运行，或者在命令行执行：
   ```bash
   <SDK目录>/renpy.sh PZK_GAME run
   ```
   macOS 上用 `renpy.app/Contents/MacOS/renpy`。
2. **语法检查（lint）**：把上面的 `run` 换成 `lint`。提交前必须零报错，图片和音频路径缺失也会报出来。
3. **跳章**：标题菜单 →「章节选择」，可以直接从任意一章开始。从中间开始时，之前的选择按默认值处理。
4. **自动通关测试**：随机走所有分支。
   ```bash
   cd PZK_GAME && python3 tools/autotest/run.py 20
   ```
   - 加上 `PZK_START=chapter4` 可以从指定 label 开始。
   - 系统规则自测：`PZK_START=sys_selftest python3 tools/autotest/run.py 1`，日志里应有 `SELFTEST PASS`。
   - 日志在 `PZK_GAME/autotest_logs/`，已加入 `.gitignore`。
   - 脚本里的 SDK 路径默认是 `/Volumes/renpy-8.4.1-sdk/...`，换电脑要改 `tools/autotest/run.py` 第 4 行。
   - 原理：快进对话；用种子随机选选项；限时选项有 30% 概率故意超时；只靠计时器关闭的卡片会直接跳过。
5. 自动测试只保证不报错、所有分支都能走通。节奏、文字和画面还是要人工玩一遍。

## 2. 代码结构

```
PZK_GAME/game/
  script.rpy       序章 + 总入口（label start）
  Chapter1~4.rpy   各章剧情（见上表）
  characters.rpy   所有 Character 定义
  variables.rpy    第一部的数值与剧情标记（default）+ stat() 函数
  system_data.rpy  系统数据表：可扫描的人物、专属奖励（加新人物只改这里）
  system.rpy       纯爱致富系统：状态、规则函数、所有系统界面、演出用 label
  phone.rpy        手机界面：微信聊天、红包、朋友圈
  assets.rpy       所有图片和音频的登记（剧本里只用名字，不写路径）
  transforms.rpy   站位与动画
  hud.rpy          HUD、飘字、章节标题卡、结算画面、章节选择、UI 风格覆盖
  screens.rpy / gui.rpy / options.rpy   Ren'Py 自带（改动很少）
PZK_GAME/tools/    素材生成脚本与测试工具（不会打包进游戏）
PZK_GAME/docs/     设计文档（本文件、system_design.md、storyboard_ch1_part2.md）
```

### 必须遵守的代码约定
- **存档变量**：会存进存档的变量一律用 `default` 声明，常量用 `define`。不要在剧情里直接 `$ 新变量 = ...` 而不先 default，否则旧存档会出问题。
- **不要改已有的 label 名**：存档、跳转、章节选择都依赖它们。
- **立绘命名**：`<角色> <服装> <表情>`，例如 `show pzk delivery shock`、`show lxx casual tongue`。每次 `show` 都写全三段，不要依赖属性推断。
- **站位**：`left_stage` / `right_stage` / `center_stage` / `far_right`；晚餐坐姿用 `seated(x)`；特写用 `closeup`；镜子用 `mirror_view`。
- **改数值**：
  - 第一部：`$ stat("yyl_aff", 5)`、`$ stat("zb", 5)`、`$ stat("sincere", 5)`。真诚值是隐藏的，不会弹提示。
  - 系统阶段：`call sys_love("dhy", 5)`（其余用法见第 5 节）。
- **数值显示规则**：系统正式激活前（包括初级扫描阶段），右上角和飘字都不显示任何数值（只在内部记录）。激活后才出现系统 HUD（真实余额、舔狗基金、当前对象好感与封印）。社死值已删除，不要再加回来。
- **台词里的百分号**：要写成 `%%`，例如 `"好感度：[x]%%。"`，否则 lint 报错。
- **界面里取字典的值**：用 `[t['name']]`，引号不能省。

## 3. 世界观与时间线

- **背景**：现代中国。第一、二章是 2066 年（手机上显示 2066 年 6 月 6 日），第三章是两年后的 2068 年。科技与现在差不多，只是一个设定梗，不要写科幻元素。
- **第一部（海岛）**：热带度假海岛。潘子恺在海景别墅度假，开蓝色兰博基尼「小蓝」送外卖体验生活。
- **转折（第二章）**：岛上最后一晚，酒店顶层仙人跳。他签下「和解协议」「资产代持授权」「紧急委托书」，资产被转走好几层，部分到了境外。
  - 剩下的全部财产：¥1,872.50、一张回城机票、外卖电动车「小黄」（骗子嫌它不值钱）。
- **两年空白**：破产后他回到城里，一直送外卖。两年里的事除第三章提到的以外都没写，可以按需补，但不要和第三章冲突。
- **第二部（城里，2068）**：
  - 住处：城中村八平米出租屋，房东老陈，月租八百。
  - 工作：在「岛团外卖」站点跑单，站长老刘。
  - 常去：一家平价足疗店（前台王姐；熟悉的技师小芳已离职嫁人）。
  - 老东家：投行在「环球金融中心 A 座 48 楼」，大堂背景墙上写的是「鼎峰资本」。
- **平台**：「岛团外卖」是虚构平台。岛上和城里用的是同一个 App，提示音和台词都一样，这是一个梗。

## 4. 人物设定（定死的部分，续写不能改）

### 潘子恺（主角，玩家）
- **身份**：第三章时 25 岁（海岛时 23 岁）。以前是投行分析师，在李轩翔手下干过；后来靠押对几只股票财富自由，辞职；被仙人跳骗光后，已经送了两年外卖。
- **两年后的变化**：习惯了穷——看天气接单、算电量、为几块钱配送费和罚款精打细算、吃盒饭泡面。装逼从「炫富」变成「苦中作乐」（抢到五元券当成一笔惊天交易）。被骗过，对主动示好的陌生人很警惕。
- **感情经历**：**不是处男**，富豪时期谈过不少恋爱（平均十一天）。三位前女友系统评分 89/89/88。见到美女不会慌，有社交经验和情商，只是钱和底气没了。
- **性格**：极度自恋、爱装逼、花心、自认情圣；嘴硬，经常装逼失败。但不坏，也不蠢：有真本事（尽调、做模型），记性好，心软。
- **口头禅风格**：
  - 「女娲捏我的时候是不是开了会员」
  - 「我这辈子最大的缺点就是找不到自己的缺点」
  - 天塌下来也先吐槽一句，反应永远比事件低一档。
- **成长线**：从「靠钱和脸」变成「靠真心和本事」。每一次真诚的选择都应该被奖励，每一次装逼都应该有代价，但代价要好笑，不要惨。
- **立绘**（写实照片风格）：
  - `pzk casual *`：紧身背心
  - `pzk surf *`：花衬衫
  - `pzk delivery *`：黄色外卖服，破产后主要用这套
  - 封印梗专用：`pzk delivery sealed` / `pzk casual sealed`，腰间贴着「纯爱封印」符纸
- **固定资产**：电动车「小黄」。
- **系统自扫评分**：**-250**（区间 0～100，系统也是第一次见）。

### 杨永麟（第一部女主，目前退场但非常重要）
- **基本**：25～26 岁，高冷、洒脱、毒舌、会冲浪（每天早上六点），上岸穿黑色细高跟鞋，在沙滩上也穿。
- **背景**：自称做风控，以前在大城市银行风控部，在里昂待过两年，会法语。
- **说话方式**：极简、一针见血，偶尔露出幽默和温柔，不是傲娇。
- **身份是悬念（最重要的悬念）**：她在仙人跳里到底是什么角色，**目前绝对不能揭示**。她可能是主谋、可能是同伙、也可能同样是受害者。续写时不要替她洗白，也不要把她写死成反派，两种可能都要留着。
- **她的标志物**：黑色高跟鞋、冰椰子水、蓝色海玻璃、联系人「K」。
- **立绘**：`yyl *`，写实照片风格，花衬衫。

> **注意**：下面李轩翔、沈眠、秦受的「已揭示」细节、以及丁虹依精品店柜姐等身份，来自已删除的旧剧情。外形、性格可以继续用；旧剧情里发生的具体事件**不算数**，要用的话由项目负责人决定。

### 李轩翔（系统数据：96 分，专属奖励「生化人保镖」；新时间线里还没出场）
- **身份**：31 岁，顶级投资银行投资银行部董事总经理（MD），全行最年轻的 MD。潘子恺以前的直属上司。
- **外形**：蜂蜜金短发，无框茶色眼镜，红唇。
  - 白天：黑西装、白丝衬衫、包臀裙、黑丝、细高跟。
  - **晚上十点以后**：换上红色皮衣，内搭黑色高领、十字架项链，灰色宽松牛仔裤。
  - 系统颜值评分 96（只存在于系统内部，**任何角色都不能当面说出分数**）。
- **性格**：强势、冷静、果断，靠实力上位，最讨厌没能力还吹牛的人。
  - 会议不许超过二十分钟；PPT 字号必须统一，错一个标点打回重做。
  - 潘子恺当年的 PPT 被她打回 17 次，第 18 次的批注是「可以」。
- **她的另一面（第四章已揭示）**：
  - 睡不着的时候去 24 小时抓娃娃店，用保夹机制建模（「第二百四十次，误差为零」）。
  - 养了一只猫叫「止损」。
  - 害怕的时候会把笔放得很慢。
  - 偶尔会吐舌头、说「略」。这是极少数时刻才出现的失态，**不要滥用**，一章最多一两次。
  - 晚饭常常只有咖啡：双份浓缩，不加糖。深夜加班要吃煎饼：加三个蛋，不要香菜。
- **说话方式**：短句、数字、逻辑，从不说废话；最狠的话说得最轻。
- **立绘**：Gemini 生成的写实风格，用户已审核。
  - 职业装：`lxx cold / smirk / angry / surprised / speechless / smile / laugh / blush / tired / tongue`
  - 皮衣：`lxx casual cold / smile / blush / surprised / tongue`
  - 剪影：`lxx silhouette`
- **CG**：`cg reunion`（48 楼重逢）、`cg claw_machine`（抓娃娃店）。

## 5. 纯爱致富系统的规则（核心设定，不能改）

完整说明和代码用法见 [`system_design.md`](system_design.md)。摘要：

| # | 规则 | 代码 |
|---|---|---|
| 0 | 三个阶段：未出现 → 初级扫描（只看姓名/年龄/评分）→ 正式激活（向 ≥ 90 分成年女性完成第一次被接受的赠与） | `sys_stage` |
| 1 | 扫描自由：任何人、照片都能扫；陌生人只显示姓名、年龄、颜值评分 | `call sys_scan(pid, photo=False)` |
| 2 | 成年女性且评分 ≥ 90 才符合攻略条件 | `eligible(pid)` |
| 3 | 成功赠与 → 解锁人物特点、当前好感度、专属奖励、攻略状态；拒收或未完成不解锁 | `call sys_gift(...)` |
| 4 | 赠礼不等于好感；每人好感独立；≥ 90% 成功 → 解除她的封印 + 发她的专属奖励 | `call sys_love(pid, ±N)` |
| 5 | 纯爱封印：每个已解锁档案的对象单独生效（功能性阳痿梗，不写露骨内容） | `call seal_alarm("台词")` |
| 6 | 多目标从一开始就支持；系统不指定攻略谁；不提供精神控制 | `pursuing()` |
| 7 | 舔狗基金：真钱 1 元 = 10,000 元基金，不可退；只能花在任意 ≥ 90 分成年女性身上（她收到真钱）；自购、套现、无关消费一律驳回 | `call sys_recharge(元)`、`call sys_spend(...)` |
| 8 | 基金不是宿主的个人财富；激活那笔赠与不算充值；专属奖励与基金独立；暂无好感返现 | — |

专属奖励：丁虹依「超强体魄」、李轩翔「生化人保镖」，其他人由项目负责人决定。旧的纯爱卡、任务系统、一千万奖金、自动指定目标都已删除。

## 9. 写作风格守则

### 必须做
- **第一人称**：短句，多用对话、动作和表情差分推进，少写大段旁白。
- **喜剧来自人物和反差**，不靠堆网络梗。
  - 潘子恺：夸张反应 + 离谱视角，钝感吐槽，「行吧。」
  - 系统：一本正经地宣布荒唐的事，毒舌。
  - 李轩翔：轻描淡写 + 一针见血，数字和逻辑。
  - 杨永麟：极简 + 反问。
- **梗要能长出来**：系统规则就是一台「困境机器」。每次重复同一个梗都要换一层意思，最后一次要反转。
- **运行中的梗**（续写时可以继续用）：
  - **报销审核**：被拒的东西越贵越好笑；给她买的东西越便宜越容易秒批。
  - **纯爱封印**：每次触发，他的反应和系统的语气都在变化。
  - **奇怪的订单备注**：黑色高跟鞋 → 敲三下 → 第三排第七台 → 黑色高跟鞋。
  - **「可以」**：第一次是四年前 PPT 第 18 版的批注，第二次是第四章会议，第三次留给 90%。
  - 「消防通道」、「小黄比小蓝可爱」、「九分袖」、「四舍五入」。
  - 枕头边的物件越来越多：海玻璃 / K 便签、猫猫娃娃。
- **节奏**：不能每句都是梗。要有正常对话、尴尬沉默、偶尔的温柔，**真情只在关键处放一两拍**，放的时候收起吐槽，写得朴素。
- **女主要有独立人格**：有自己的事业、判断和不为钱所动的理由。好感只能靠具体事件积累，不能靠送几次礼物就爱上。

### 不能做
- 不写露骨性描写。成人向幽默靠双关、黑屏、系统提示和吐槽。
- 任何角色都不能当面说出颜值分数。
- 不揭示杨永麟和 K 的真实身份；不解释梦境反转的原因。
- 系统不能控制或强迫任何角色的感情。
- 不要用大段严肃、文艺、像传统小说一样的旁白。
- 不要把社死值加回来；系统觉醒前不要显示数值。

### 李轩翔立绘的生成流程（新角色可照抄）
1. **准备 API Key**：在自己的电脑上存一个 Gemini API Key 到 `~/.config/pzk/gemini_key`。**不要把 Key 写进仓库，也不要发在聊天里。**
2. **参考照片**：放在 `PZK_GAME/tools/art/ref/`。**这个目录已被 `.gitignore` 忽略**，里面是真人照片和 AI 原图，不提交、不公开。
3. **生成**：在 `tools/art` 目录下运行。
   ```bash
   PZK_GEMINI_MODEL=gemini-3-pro-image PZK_IMAGE_SIZE=2K python3 genai_lxx.py master --n 3
   ```
   这一步生成定妆照候选，送审。通过的那张命名为 `ref/genai/master.png`，再运行 `variants` 生成表情。
4. **导入游戏**：`python3 import_lxx_genai.py`。用 macOS Vision 抠图（`person_mask.swift`），统一到 1024×1536 的画布，头部大小和潘子恺一致。
5. **CG**：`python3 gen_lxx_cg.py`。依赖 `ref/` 里的一张娃娃机素材，所以换电脑后抓娃娃那张 CG 重新生成不了，但成品已经提交了。

### 其他素材
- **背景和 CG**：`tools/art/gen_*.py`，运行 `python3 <脚本> [名字]` 可以单独重建。
- **音乐和音效**：全部是程序合成的原创内容。
  ```bash
  <装了 numpy/scipy/soundfile 的 python> tools/audio/generate_all.py [名字…]
  ```
  加 `--verify` 只做检查。
- **项目原有音乐**：`main_song.mp3`、`Beach_Song.mp3`、`pzk-rich.mp3`、`pzk_rap.mp3`。
- **新增素材**：在 `assets.rpy` 里登记，用 `A("bgm/xxx")` 自动选择 ogg/wav/mp3。
